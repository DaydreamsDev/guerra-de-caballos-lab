# archaeology-13 — Technical documentation for maintainers

> [English](README.md) | [Español](README-es.md)

> **Status:** drafted · **Concept:** documentation · **Prerequisite:** archaeology-03 ·
> **Estimated time:** 60 minutes

This lesson turns the evidence from the earlier lessons into documentation a maintainer can use: a
README, a behavior spec and exact build/run/test instructions. It documents the artifact, not its
context.

## What the learner does

- Chooses one legacy source.
- Fills `README-TEMPLATE.md` and `SPEC-TEMPLATE.md`.
- Writes exact commands for build, run and test.
- Checks every command and every claim against the source.
- Records what remains unknown.
