# archaeology-13 — Documentación técnica para mantenedores

> [English](README.md) | [Español](README-es.md)

> **Estado:** borrador · **Concepto:** documentación · **Prerrequisito:** archaeology-03 ·
> **Tiempo estimado:** 60 minutos

Esta lección convierte la evidencia de las lecciones anteriores en documentación que un mantenedor
puede usar: un README, una especificación de comportamiento e instrucciones exactas de compilación,
ejecución y prueba. Documenta el artefacto, no su contexto.

## Qué hace la persona que aprende

- Elige una fuente heredada.
- Completa `README-TEMPLATE-es.md` y `SPEC-TEMPLATE-es.md`.
- Escribe comandos exactos de compilación, ejecución y prueba.
- Comprueba cada comando y cada afirmación contra la fuente.
- Registra qué sigue desconocido.
