# archaeology-17 — Code review of a legacy function

> [English](README.md) | [Español](README-es.md)

> **Status:** drafted · **Concept:** code review · **Prerequisite:** archaeology-04 ·
> **Estimated time:** 60 minutes

This lesson applies code review to one legacy function. The learner reads the function, writes
findings with evidence and severity, prioritizes them, and names one test that would catch the
highest-risk finding. It is about review judgment.

## What the learner does

- Chooses one function from the legacy source.
- Fills `CODE-REVIEW-TEMPLATE.md`.
- Writes at least three findings with line evidence and severity.
- Prioritizes the findings by consequence.
- Names one test that would catch the first finding.
