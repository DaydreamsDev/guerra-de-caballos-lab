# archaeology-17 — Revisión de código de una función heredada

> [English](README.md) | [Español](README-es.md)

> **Estado:** borrador · **Concepto:** revisión de código · **Prerrequisito:** archaeology-04 ·
> **Tiempo estimado:** 60 minutos

Esta lección aplica revisión de código a una función heredada. La persona lee la función, escribe
hallazgos con evidencia y severidad, los prioriza y nombra una prueba que detectaría el hallazgo de
mayor riesgo. Se trata del juicio de revisión.

## Qué hace la persona que aprende

- Elige una función de la fuente heredada.
- Completa `CODE-REVIEW-TEMPLATE-es.md`.
- Escribe al menos tres hallazgos con evidencia de línea y severidad.
- Prioriza los hallazgos por consecuencia.
- Nombra una prueba que detectaría el primer hallazgo.
