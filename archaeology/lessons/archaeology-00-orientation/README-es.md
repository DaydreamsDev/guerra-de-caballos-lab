# archaeology-00 — Orientación: leer un código heredado

> [English](README.md) | [Español](README-es.md)

> **Estado:** borrador · **Concepto:** modelo mental · **Prerrequisito:** common-04 ·
> **Tiempo estimado:** 45 minutos

Esta lección inicia la pista B con la tarea de ingeniería: leer una fuente desconocida y construir
un modelo mental. Mapea el punto de entrada,
las funciones, el estado y el flujo de datos para que las siguientes lecciones tengan un objetivo.

## Qué hace la persona que aprende

- Lee el punto de entrada y la lista de funciones.
- Completa `CODE-MAP-TEMPLATE-es.md`.
- Ejecuta la compilación y registra la primera salida observable.
- Escribe un propósito en una frase y la siguiente pregunta.
