# archaeology-00 — Orientation: read a legacy codebase

> [English](README.md) | [Español](README-es.md)

> **Status:** drafted · **Concept:** mental model · **Prerequisite:** common-04 ·
> **Estimated time:** 45 minutes

This lesson starts Track B with the engineering task: read an unfamiliar source and build a mental
model. It maps the entry point,
functions, state and data flow so the next lessons have a target.

## What the learner does

- Reads the entry point and the function list.
- Fills `CODE-MAP-TEMPLATE.md`.
- Runs the build and records the first observable output.
- Writes a one-sentence purpose and the next question.
