# archaeology-02 — Code inventory and call graph

> [English](README.md) | [Español](README-es.md)

> **Status:** drafted · **Concept:** structural inventory · **Prerequisite:** archaeology-01 ·
> **Estimated time:** 60 minutes

This lesson inventories the source as a system: files, functions, globals, calls and entry points.
The output is a call graph and an inventory table that later lessons can use.

## What the learner does

- Counts files, functions and globals.
- Fills `CODE-INVENTORY-TEMPLATE.md`.
- Draws the call graph.
- Names the largest function, the most connected function and the most mutated global.
- Records what cannot be classified.
