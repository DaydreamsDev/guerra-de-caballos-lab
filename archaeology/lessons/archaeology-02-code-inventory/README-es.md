# archaeology-02 — Inventario de código y grafo de llamadas

> [English](README.md) | [Español](README-es.md)

> **Estado:** borrador · **Concepto:** inventario estructural · **Prerrequisito:** archaeology-01 ·
> **Tiempo estimado:** 60 minutos

Esta lección inventaría la fuente como sistema: archivos, funciones, globales, llamadas y puntos de
entrada. El resultado es un grafo de llamadas y una tabla de inventario que las siguientes lecciones
pueden usar.

## Qué hace la persona que aprende

- Cuenta archivos, funciones y globales.
- Completa `CODE-INVENTORY-TEMPLATE-es.md`.
- Dibuja el grafo de llamadas.
- Nombra la función más grande, la más conectada y el global más mutado.
- Registra qué no puede clasificar.
