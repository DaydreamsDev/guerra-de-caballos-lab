# Pista A — Construcción

> [English](README.md) | [Español](README-es.md)

**Pregunta:** *¿Cómo construyo lo mismo con otra forma de pensar?*

Esta pista construye el mismo comportamiento del juego mediante una secuencia de decisiones de
diseño. El juego es el invariante; el costo del siguiente cambio es la lección.

## Qué hace quien aprende

- Parte de un artefacto que funciona.
- Predice el efecto de un cambio de diseño.
- Implementa solo ese cambio.
- Compara el comportamiento observado con la predicción.
- Explica la brecha.
- Registra la evidencia.

## Alcance

El alcance mínimo de la primera entrega es `construction-00` a `construction-09`:

- flujo de control;
- agregación;
- indirección;
- modularidad;
- tipo abstracto de datos.

La escalera completa está en borrador hasta `construction-24`. La versión moderna con clases está
cubierta por:

- `construction-11` — encapsulación.
- `construction-12` — polimorfismo.
- `construction-13` — composición.

Estas lecciones son extensiones curriculares modernas, no código histórico reconstruido.
