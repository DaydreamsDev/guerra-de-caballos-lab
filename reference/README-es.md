# Implementación de referencia

> [English](README.md) | [Español](README-es.md)

Este directorio contiene la implementación «debería ser» producida por la pista A.

La pista B apunta a esta implementación cuando una tarjeta de fallo pregunta cómo debería verse el
código reparado. La referencia conserva el comportamiento del juego y las trazas de referencia.

## Estado

Implementada. Se basa en la línea base final de la pista A y coincide con
las 20 trazas de referencia.

## Compilar y ejecutar

```bash
./run.sh --seed 1 --name Learner
```

## Regla

La referencia es un artefacto didáctico moderno, no un reemplazo del código histórico. El archivo
sigue siendo la evidencia.
