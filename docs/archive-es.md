## Qué contiene el archivo

- `variant-00` — precursor de 2007.
- `variant-01` — línea base de 2008.
- `variant-02` — registros de 2008.
- `variant-03` — desarrollo con punteros de 2008.
- `variant-04` — punteros finales de 2008.
- `variant-05` — clases, documentado como ausente.
- Procedencia, inventario, taxonomía, linaje, estado de compilación, problemas conocidos e informes
  de restauración.

## Qué no contiene el archivo

- Una implementación con clases.
- Una compilación moderna.
- Una rama de corrección de errores.
- Las lecciones del laboratorio.

El archivo es evidencia. El laboratorio construye la capa moderna de aprendizaje.

## Regla

No edites el archivo desde este repositorio. Si hace falta una corrección histórica, pertenece a una
nueva versión del archivo, no a una lección.
